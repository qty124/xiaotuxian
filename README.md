# 🐰 小兔鲜儿 — 生鲜电商官网

> Web 前端编程技术实验作品 · 纯静态页面（HTML + CSS + JavaScript）

一个面向生鲜果蔬零售场景的品牌官网原型，包含首页导航、轮播图、商品网格与响应式布局。

## 🔗 在线预览

**https://qty124.github.io/xiaotuxian/**

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 顶部导航 | 响应式汉堡菜单，移动端可折叠 |
| 轮播图 | 首页 Banner 自动轮播，支持手动切换 |
| 商品网格 | 生鲜分类展示，响应式栅格布局 |
| 学生信息 | 课程作业署名信息区块 |
| 图片资源 | 全套本地化图片（`images/`），无外链依赖 |

## 📁 结构

```
xiaotuxian/
├── index.html          # 单页入口，含全部区块
├── css/style.css       # 样式表（布局 / 主题 / 响应式）
├── js/main.js          # 交互逻辑（导航 / 轮播）
└── images/             # 图片资源（LOGO / Banner / 商品图）
```

## 🛠 技术栈

- **HTML5** — 语义化标签结构
- **CSS3** — Flexbox / Grid 布局、响应式媒体查询、过渡动画
- **Vanilla JavaScript** — 无框架依赖，原生 DOM 操作

## 🚀 本地运行

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：起个本地静态服务器（推荐，路径更规范）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
